# Session 41 (low-spec step 0, docs\native\LOWSPEC_PLAN.md): the laptop / playtester performance test with the per-pass
# GPU breakdown. Self-contained (inline state chains, no includes, no states.toml), so it runs from a test zip next to
# wwe2k14.exe (as perf_test.txt; the launcher's PERFORMANCE TEST runs it twice: the LOW preset (accurate + native
# renderer, fast clears), then the light renderer, both at 720p and frame rate 30). Boots to the main menu, takes a
# frame-anatomy capture with GPU marks (2 frames, sparse marks) there, at Bryan's entrance +440 frames and at the match
# +600 frames (logs\anatomy_NNN_K*.csv; Session 43: K = 0 menu, 1 Bryan, 2 Bryan with gpu_native_post +
# gpu_native_after_scene (Session 42), 3 Bryan with every Session 43 native setting (post, post depth, 16-bit,
# quantize, scene extras, after-scene), 4 match, 5 match with the Session 42 pair, 6 match with the Session 43 set;
# each capture's label is in its "perf: capture K ..." log line), and switches the fast clears on and off every 120
# frames in Brock's entrance and from Bryan's through the start of the match (logged as "ab: mode 1 / 0"; the light
# renderer has no fast clears: its pairs are the test's own check, about 0). Read with py tools\native\laptop_breakdown.py ZIP.
